## **Gestion des commandes**

1-Description du projet
Ce projet est :gestion des commandes developee avec HTML,CSS, Javascripte et des fichier JSON.Elle permet de consulter les clients ,les produits ,et les commandes ,de rechercher des commandes et de filtrer les resultats et calculer le montant total de chaque commande

2-  la structure générale du projet :

TP4/
│
├── index.html
├── README.md
│
├── css/
│   └── style.css
│
├── data/
│   ├── customers.json
│   ├── products.json
│   └── orders.json
│
└── js/
    ├── app.js
    ├── state.js
    ├── dataservices.js
    ├── selectors.js
    └── view.js

 3- les fonctionnalités principales :
Affichage des commandes dans un tableau.

Recherche d'une commande par le nom du client.

Filtrage des commandes selon leur statut.

Filtrage des commandes selon la catégorie des produits.

Affichage des informations 

Calcul 

Affichage des statistiques : nombre de clients, nombre de produits, nombre de commandes et montant total.

Affichage des détails d'une commande.

4-  les instructions pour lancer le projet
  
J ai ouvrir le dossier TP4 dans VS CODE , faire un clic droit sur index.html et selectionner OPEN WITH LIVE SERVER
